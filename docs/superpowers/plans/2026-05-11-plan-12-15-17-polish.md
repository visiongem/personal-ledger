# Plan 12+13+14+15+17 · Polish pack（图表 / 备份 / 多 backstack / picker / 跨币种）

> **For agentic workers:** Use superpowers:subagent-driven-development.

**Goal:** 把 v1 主体能力上的"打磨层"一次打掉。完成后体验显著贴近 spec 设计：每 tab 独立栈、统计带图、备份导出导入、跨币种汇总、picker 美化。

---

## 范围决策（明确取舍）

- **Plan 12（图表）**：Compose Canvas 自绘**水平条形图**展示分类支出 breakdown。**不引入外部图表库**（Vico / MPAndroidChart 都太重）；折线/饼图留 v2。
- **Plan 13（备份）**：**CSV 导出 + 导入**两个动作，通过 Android SAF (`ActivityResultContracts.CreateDocument` / `OpenDocument`) 调系统文件选择器。**ZIP 全量备份留 v2**。导出仅 records 表（账户/分类/预算等需要做迁移规划，留 v2）。
- **Plan 14（multi backstack）**：每个 tab 独立 `mutableStateListOf<Any>`，切 tab 时保留对侧栈位置；用 `rememberSaveable` 跨配置变更存活。
- **Plan 15（picker）**：把 `ExposedDropdownMenuBox` 改成 `ModalBottomSheet`-based `ViaBottomSelector`，封到 core-ui，feature-record 与 feature-account（创建账户的币种待 v2）切换调用。
- **Plan 17（跨币种汇总）**：StatsHomeViewModel 用 `ExchangeRateRepository.observeLatest` 查 source→default 汇率，做账户币种 → 默认币种折算；找不到汇率的账户标 "(no rate)" 而非崩。**不自动 refresh**——Settings 加一个手动 "Refresh rates" 按钮。
- **跳过 Plan 16（DAO 集成测试）**：Robolectric + JUnit 5 + Hilt 整合工程量大且需要真机闭环验证，留装机后单独处理。

## Tasks

### T1（P14）：每 tab 独立 backstack

修改 `MainActivity.LedgerApp()`：
- 用 `Map<TopLevelKey, SnapshotStateList<Any>>` 维护 4 个栈
- 当前显示的 backStack 由 `selectedTab` 状态决定
- 切 tab 不清栈；返回键作用于当前 tab 的栈
- 用 `rememberSaveable` 保证旋转/进程死亡后能恢复栈（要求路由数据类是 Parcelable 或 Saver——v1 简化：仅记录当前 tab，栈本身用 `remember`，配置变更丢失子页面 OK；spec 范围内 acceptable）

Commit: `feat(app): per-tab backstack so sub-pages survive tab switches`

### T2（P15）：ViaBottomSelector + 替换 dropdown

- Create `core-ui/.../component/ViaBottomSelector.kt`：`@OptIn(ExperimentalMaterial3Api::class)` 包 `ModalBottomSheet`，参数 `items: List<T>`、`itemLabel: (T) -> String`、`onSelect: (T) -> Unit`、`onDismiss: () -> Unit`
- 在 `feature-record/RecordEditScreen` 把 Account / Target Account / Category 三个 dropdown 都换成"显示一个可点击的 OutlinedTextField，点击打开 BottomSheet"
- 测试用 Preview + 编译验证（UI 行为无 JVM 单测）

Commit: `feat(core-ui): add ViaBottomSelector and adopt in RecordEdit`

### T3（P12）：分类支出条形图

- Create `core-ui/.../component/ViaHorizontalBarChart.kt`：纯 Compose Canvas，输入 `entries: List<BarEntry(label, value, color)>`；每行渲染 label + 占满宽度的相对长度条；最大值条满宽，其余按比例
- 修改 `feature-stats/StatsHomeScreen.kt`：在分类 breakdown 文字列表上方加 `ViaHorizontalBarChart`，data 来自 state.expenseByCategory
- 颜色：按分类轮换 4 种主题色（primaryContainer 系）

Commit: `feat(core-ui): add ViaHorizontalBarChart and render category breakdown`

### T4（P17）：跨币种汇总

- 修改 `feature-stats/StatsHomeViewModel`：
  - 注入 `AccountRepository` + `ExchangeRateRepository`
  - combine 现有 4 个 flow + accounts + per-account latest rates
  - 对每个 record，按其账户币种查 base→defaultCurrency 汇率，无则跳过该 record 并在 UI state 中累计 `unconvertedCount`
  - income/expense/net 都在 defaultCurrency 下汇总
- UiState 加 `unconvertedCount: Int`，未折算时 Screen 顶部显示 "{N} records skipped — currency rate missing"
- 加 `:feature-settings` `SettingsHomeViewModel.refreshRates()`：调 `exchangeRateRepository.refreshLatest(base = default, quotes = all distinct account currencies)`；Settings UI 加一个 "Refresh exchange rates" 按钮

Commit: `feat(feature-stats): convert per-account amounts to default currency`

### T5（P13）：CSV 导出/导入

- Create `core-data/.../backup/RecordCsv.kt`：纯 Kotlin format/parse helpers
  - 列：`id,occurredOn,accountId,categoryId,type,amount,note,transferToAccountId,transferAmount`
  - 头一行固定，escape 逗号用引号
  - 提供 `List<Record>.toCsv(): String` 和 `String.toRecordsOrNull(): List<Record>?`
  - JVM tests ≥4：round-trip / 空文件 / 含逗号/引号的 note / 解析失败回 null
- Create `core-data/.../backup/RecordBackupRepository.kt`：暴露 `suspend fun exportToCsv(): String` 和 `suspend fun importFromCsv(text: String): Result<Int>`（重复 id 走 upsert）
- 修改 `feature-settings/SettingsHomeScreen.kt`：加 "Export records (CSV)" 和 "Import records (CSV)" 按钮，用 `rememberLauncherForActivityResult(CreateDocument / OpenDocument)` 触发 SAF
- ViewModel 加 `exportRecords(uri: Uri)` / `importRecords(uri: Uri)` 通过 ContentResolver 读写

Commit: `feat: CSV export/import via SAF`
